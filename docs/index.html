〇、隐私同意机制

  • 首次启动弹窗：首次启动时展示本政策与《用户协议》，您可以选择“同意”或“不同意”。不同意时本游戏将退出，不初始化登录、广告、统计、崩溃诊断类第三方 SDK，不收集个人信息。
  • 必选与可选分开：登录、实名认证、云存档为提供游戏服务所必需；统计分析、崩溃诊断、个性化广告为可选授权，默认关闭，可随时在“设置 → 隐私设置”中开启或关闭，拒绝不影响基础游戏功能。
  • 同意后初始化：仅同意后才初始化 TapTap SDK、TapADN 聚合广告 SDK、友盟统计 SDK、腾讯 Bugly 崩溃收集 SDK；其中友盟、Bugly 还须对应可选授权开启；个性化广告须对应开关开启。
  • 撤回同意：“设置 → 隐私设置 → 撤回全部同意”可撤回全部授权并退出应用；撤回不影响此前基于同意已进行的处理。
  • 重新同意：本政策更新时，应用内会重新展示并需要您再次同意；您可拒绝更新后的政策并停止使用。
  • 应用内查看：“设置 → 隐私与协议 → 隐私政策”可随时查看本政策；完整可点击版本见 https://hsmy7.github.io/mnzm-policy/。

1.1 TapTap 账户与实名信息

本游戏全部功能需要登录后使用。实名认证由 TapTap 合规 SDK 完成并提交国家新闻出版署网络游戏防沉迷实名认证系统；我们不自行收集、存储或传输您的身份证号码，仅接收年龄/认证结果用于防沉迷。手动认证场景下电话号码由 TapTap 收集，我们不自行设计电话号码输入框。电话号码属于敏感个人信息，TapTap 会在其界面单独告知并征得同意。

1.2 网络状态与本地存储

我们检查网络连接状态用于判断网络是否可用。Android 9 及以下请求外部存储读写权限用于保存本地存档；Android 10 及以上使用分区存储，无需额外权限。完整权限清单见第二节。

四、敏感个人信息与单独同意

实名认证信息（姓名、身份证号）、电话号码、精确/粗略位置、广告标识符属于敏感个人信息或需单独告知的信息。我们按以下方式处理：① 实名信息由 TapTap 合规 SDK 在其界面单独告知并征得同意后收集，我们不存储身份证号；② 电话号码仅在手动认证场景由 TapTap 收集，我们不自行收集；③ 位置权限仅为广告 SDK 建议权限，App 不主动请求；④ 广告标识符仅用于广告投放与归因，您可关闭个性化广告或卸载应用停止收集。拒绝提供上述信息不影响基础游戏功能（法定必需除外）。

五、信息使用目的

  • 提供游戏核心功能：登录、存档、防沉迷、排行榜、云存档；
  • 广告变现：展示激励视频广告并提供游戏内奖励；
  • 统计分析（可选）：了解新增、活跃、启动、版本与渠道分布，改进产品；
  • 崩溃诊断（可选）：定位并修复闪退、卡死；
  • 安全与合规：本地加密、请求签名、防重放、兑换码防刷、履行法定义务。

自动化决策：个性化广告会基于设备标识符与广告交互数据进行兴趣推送；您可在游戏内“个性化广告”开关中关闭，关闭后不再基于您的兴趣推送。我们不会将您的个人信息用于上述目的以外的用途。

六、信息存储与保护

  • 存档按 TapTap 账号隔离：不同账号互不可见；退出登录只解除绑定不删除存档，同账号重新登录后进度仍在。
  • 存档保存在设备本地（AES-256-GCM 加密）；云存档为序列化并压缩后上传，用于跨设备恢复，不额外加密。
  • 账户信息使用 AES-256 加密的 EncryptedSharedPreferences 保存。
  • 网络通信强制 TLS 1.2/1.3，启用证书固定与 AEAD 套件，每个请求自动注入 HMAC-SHA256 签名。
  • 设备标识符仅以哈希形式参与本地密钥派生；网络请求仅发送 SHA-256 摘要前 8 位。
  • 存储位置：中华人民共和国境内（本地设备、境内 TapTap 云服务、境内腾讯 Bugly 平台）；除本政策所列第三方在其服务范围内处理外，不存在数据跨境传输。

6.1 个人信息安全事件处置

我们制定安全事件应急预案。若发生或可能发生个人信息泄露、篡改、丢失，我们将立即采取补救措施，评估影响，并通过公告、推送、邮件等合理方式告知受影响的用户（事件基本情况、可能影响、已采取的措施、您可自主防范的建议）；同时按法律法规要求向履行个人信息保护职责的部门报告。

七、信息共享、委托处理与转移

  • TapTap SDK：登录、实名、云存档、排行榜由 TapTap 平台独立处理，受其隐私政策约束。
  • 广告 SDK：使用激励广告时，设备信息与广告交互数据与 Dirichlet、穿山甲、优量汇、爱奇艺、百青藤交互，受各自政策约束。
  • Bugly：开启崩溃诊断后，崩溃堆栈、应用版本、设备型号与系统版本、Android ID 与腾讯 Bugly 平台交互，受其政策约束。
  • 委托处理：我们可能委托云服务商等处理必要信息，并与其约定处理目的、方式、期限与安全措施；受托方不得超范围处理。
  • 转移：如发生合并、收购、资产转让等，我们会告知接收方名称与联系方式，并要求其继续按不低于本政策的标准保护您的信息。
  • 公开：除取得您单独同意或法律法规要求外，我们不会公开您的个人信息。
  • 法律要求：在法律法规要求或政府主管部门依法要求的情况下。

九、您的权利

  • 查询、复制与转移：游戏内可查看登录信息；如需个人信息副本或转移，可通过第十二节邮箱申请。
  • 更正：TapTap 账户信息请在 TapTap 平台更正；游戏内资料可在相应界面修改。
  • 删除：游戏内可删除存档/重新开始；注销账号将删除本机数据并申请删除云存档；卸载清除全部本地数据。
  • 撤回同意：“设置 → 隐私设置 → 撤回全部同意”可撤回全部授权；撤回后应用退出，下次启动重新征得同意。

  • 个性化广告/自动化决策：“设置 → 其他设置 → 个性化广告”关闭；也可在系统设置中重置/停用 GAID。
  • 投诉：通过第十二节邮箱或 TapTap 应用页面反馈，我们将在 15 个工作日内回复；您也可向网信部门（12377）或市场监管部门（12315）投诉。

十、未成年人保护

  • 我们严格遵守《关于防止未成年人沉迷网络游戏的通知》等规定，通过 TapTap 合规 SDK 实施时段与时长限制。未成年人仅可在周五、周六、周日及法定节假日 20:00-21:00 进行游戏。
  • 实名认证由 TapTap 平台完成；如识别为未成年人，按其年龄执行相应防沉迷措施。
  • 儿童（不满 14 周岁）：我们适用《模拟宗门 儿童个人信息保护规则》。处理儿童个人信息前，我们将要求监护人同意；儿童或监护人可通过第十二节邮箱查询、更正、删除儿童信息或注销账号。
  • 如发现未取得监护人同意而收集了儿童个人信息，我们将尽快删除。监护人如有疑问，可通过邮箱或 TapTap 平台联系我们。
